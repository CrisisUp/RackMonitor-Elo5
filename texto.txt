🧪 Como testar (no hardware ou Wokwi)

1. Boot do ESP32
Abra o Monitor Serial e anote a chave HMAC gerada:

text
[HMAC] Chave gerada e salva na NVS:
aB3dE5fG7hJ9kL2mN4pQ6rS8tU0vW1xY
[HMAC] Anote esta chave! Ela não será exibida novamente.

2. Configure o script Python
Edite tools/assinar_comando.py e cole a chave:

python
CHAVE = "aB3dE5fG7hJ9kL2mN4pQ6rS8tU0vW1xY"

3. Assine e publique um comando
bash
# DESARMAR
python tools/assinar_comando.py DESARMAR
# Saída: DESARMAR|1729965432|A3F5C8B2D4E6...

# Publique no MQTT
mosquitto_pub -h broker.emqx.io -t "rack_monitor_ABCD1234/comando" -m "DESARMAR|1729965432|A3F5C8..."

4. Verifique o log
text
[HMAC] Comando validado: DESARMAR
[MQTT_CMD] Desarmado remoto executado.

5. Teste rejeição
bash
# Sem HMAC
mosquitto_pub -h broker.emqx.io -t ".../comando" -m "DESARMAR"
# → [HMAC] Formato invalido. Use: COMANDO|TS|SIG

# Assinatura inválida
mosquitto_pub -h broker.emqx.io -t ".../comando" -m "DESARMAR|1729965432|INVALIDO"
# → [HMAC] Comando rejeitado: assinatura invalida.

# Replay (timestamp antigo)
mosquitto_pub -h broker.emqx.io -t ".../comando" -m "DESARMAR|1000000000|A3F5C8..."
# → [HMAC] Timestamp fora da janela

6. Teste o RESET com dupla proteção
bash
python tools/assinar_comando.py RESET
# Saída: RESET|1729965432|B4E6D8...|rack2026

mosquitto_pub -h broker.emqx.io -t ".../comando" -m "RESET|1729965432|B4E6D8...|rack2026"
# → [HMAC] Comando validado: RESET
# → [MQTT_CMD] Reset remoto executado.
⚠️ Observações importantes

1. A chave é exibida UMA vez
Após o primeiro boot, a chave fica só na NVS. Anote e guarde em local seguro. Se perder, precisará apagar a NVS (ou adicionar um comando HMAC_NEW).

2. O dashboard externo precisa ser atualizado
O dashboard atual (sem HMAC) vai ter os comandos ARMAR/DESARMAR rejeitados. Você precisa:

Adicionar o script Python ao fluxo do dashboard, ou
Implementar HMAC em JavaScript (Web Crypto API), ou
Temporariamente, usar o Serial para comandos críticos.

3. Sincronização de relógio

O HMAC usa o timestamp Unix do RTC (via NTP). Se o NTP falhar no boot, o RTC fica com hora errada e o HMAC rejeita todos os comandos. Nesse caso:
Comandos via Serial continuam funcionando (sem HMAC).
O dashboard precisa esperar o NTP sincronizar.

4. O cmdOriginal pode ser removido
No _tratarComando, a variável cmdOriginal não é mais usada. Você pode removê-la:

cpp
String cmdOriginal = cmd;  // <-- pode remover
Isso deixa o código mais limpo, mas não afeta a funcionalidade.
